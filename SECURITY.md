# Security

Report a vulnerability in these packages privately, by email to `<SECURITY_EMAIL>`, not in a public issue or a public
channel. Say which package and version, what the input is, and what happens.

What these packages promise: a name is shown only when it hashes to its record, a payment address is always
the on-chain holder's own, and with a node every answer is proven against the chain before it is given. A
case where any of those is not so is a vulnerability.
